Симулятор беспилотного самосвала (офлайн)

Запуск:
1) Откройте файл index.html двойным кликом.
2) Симулятор запустится в браузере без установки дополнительных программ и библиотек.

Управление:
- Ручной режим: W/S (газ/тормоз), A/D (поворот).
- ИИ режим: первый клик по карте = старт, второй клик = цель.
- "Сброс" перезагружает текущую карту и полный бак.

Что реализовано:
- 2 режима управления: ручной и ИИ.
- Построение выгодного маршрута (A*) с обходом препятствий.
- Учёт стоимости движения (рельеф/шероховатость) для более выгодного пути.
- Датчик топлива с расходом.
- LiDAR 360 градусов.
- Радар 360 градусов.
- Несколько реалистичных локаций карьеров.
